[前回の記事](/posts/blog-security-check-with-claude-code/)では、Claude Code と一緒にブログのセキュリティチェックをしました。

今回はその続きです。やったことは大きく分けて 3 つ。

1. **おそうじ**：ブログのフォルダを整理する
2. **アクセス解析**：何人が見てくれたかわかるようにする
3. **お守り設定**：うっかりミスでブログが壊れないようにする

今回も、Claude Code に日本語でお願いしただけです。

## その 1：ブログのフォルダをおそうじ

### 「リファクタリングして」とお願い

ブログを作っていくうちに、設定ファイルの中身があちこちに散らばってきました。そこで、こうお願いしました。

> Hugo フォルダ、リファクタリングして

**リファクタリング**とは、「**見た目や動きは変えずに、中身を整理整頓すること**」です。
部屋のおそうじで言えば、「家具の配置は変えずに、引き出しの中を整理する」ようなイメージです。

Claude Code は、こんなことをしてくれました。

- 設定ファイルを「言語」「メニュー」「見た目」などのグループに分けて、読みやすく並べ直す
- 古くなった説明文（コメント）を書き直す
- 使っていないファイルを削除する

ここで感心したのが、**整理する前と後でブログを作って見比べ、見た目が変わっていないことまで確認してくれた**ことです。
整理したつもりが何かを壊していた、という心配がありません。

### 名前をそろえる

整理の途中で、Claude Code がこんなことを教えてくれました。

> 記事に出る著者名は英語のユーザー名ですが、About ページは「ひでぶ」です。

たしかに、バラバラでした。

> 著者名をひでぶに統一してプッシュして

これで全部「ひでぶ」になりました。自分では気づかないところを見つけてくれるのは助かります。

### いらないものを片付ける

ブログを作ったときに練習用に用意した**サンプル記事**や、**中身が空っぽのフォルダ**も残っていました。

> はじめての投稿を削除してプッシュして
>
> 空のフォルダも整理してプッシュして

これでスッキリ。ブログのフォルダには、実際に使っているものだけが残りました。

> 💡 **消す前に確認してくれるので安心**
> Claude Code は削除する前に、ほかのページからリンクされていないか（消すとリンク切れにならないか）も確認してくれました。

## その 2：アクセス数を見られるようにする

ブログを公開すると、気になるのが「**何人くらい見てくれているんだろう？**」ということ。
そこで、無料で使える **Google アナリティクス（GA4）** を入れることにしました。

> GitHub Pages にブログ作ったけど、アクセス数を確認したい。Google アナリティクス（GA4）で

### ステップ 1：Google アナリティクスに登録する（自分で）

ここはブラウザで自分で進めます。Claude Code が手順を教えてくれました。

1. [Google アナリティクス](https://analytics.google.com/) を開いて、Google アカウントでログイン
2. 「測定を開始」を押して、アカウント名やプロパティ名（ブログの名前）を入力
3. タイムゾーンは「日本」、通貨は「日本円」を選ぶ
4. 「ウェブ」を選んで、ブログのアドレスを入力
5. **測定 ID**（`G-` で始まる英数字）が表示される

### ステップ 2：測定 ID を Claude Code に伝える

表示された測定 ID を、そのまま Claude Code に貼り付けるだけです。

> G-XXXXXXXXXX

> 💡 **測定 ID は秘密の情報ではありません**
> 測定 ID はブログのページの中に書かれて公開されるものなので、伝えても大丈夫です。パスワードとは違います。

### ちょっとした工夫：自分のアクセスを数えない

Claude Code が、ひと工夫してくれました。

ブログを書いているときは、自分のパソコンで何度もプレビュー（下書きの確認）をします。そのたびにアクセス数が増えたら、本当の数がわからなくなってしまいますよね。

そこで、**公開しているブログだけで数えて、自分のパソコンでのプレビューは数えない**ように設定してくれました。

### ちゃんと数えられているか確認する

1. スマホなどでブログを開く
2. Google アナリティクスの「レポート」→「**リアルタイム**」を開く
3. 「ユーザー」に **1** と表示されれば成功！ 🎉

> ⚠️ ふつうのレポート（1 日ごとのアクセス数など）は、数字が出るまで 1〜2 日かかります。最初は 0 のままでも心配いりません。

### 忘れずに：「アクセス解析を使っています」と書いておく

Google アナリティクスを使うときは、**ブログの中で「アクセス解析を使っています」と知らせること**が、Google の利用規約で求められています。

> About ページに追加してプッシュして

とお願いして、About ページに「アクセス解析ツールについて」という説明を追加してもらいました。

## その 3：うっかりミスを防ぐ「お守り設定」

最後は、**main ブランチの保護**という設定です。…と言われても、よくわかりませんよね。わたしも最初はそうでした。

> main ブランチの保護も設定って、どういうこと？

と聞いてみると、こう説明してくれました。

### main ブランチって何？

GitHub の中にある「**ブログの本番の置き場所**」のことです。ここにある中身が、そのまま公開中のブログになっています。

### 何から守るの？

GitHub には、使い方をまちがえると**ブログの中身や過去の記録が消えてしまう操作**があります。

| 危ない操作 | どうなる？ |
| --- | --- |
| **強制プッシュ** | GitHub の中身が、パソコンの中身で丸ごと上書きされる |
| **ブランチの削除** | ブログの置き場所そのものが消えてしまう |

ふだんは使わない操作ですが、うっかり実行してしまうと元に戻すのが大変です。
「保護」を設定しておくと、**この 2 つの操作を GitHub がストップしてくれます。**

### ふだんの作業は変わらない？

変わりません！

- 記事を書いて「プッシュして」 → これまでどおりできる
- GitHub のサイトで記事を直接直す → これまでどおりできる

止められるのは、危ない 2 つの操作だけです。

> main ブランチの保護を設定して

とお願いすれば、Claude Code が設定してくれます。
設定は GitHub のリポジトリの「Settings」→「Rules」→「Rulesets」から、いつでも確認・変更できます。

## 今日のまとめ

| やったこと | Claude Code へのお願い |
| --- | --- |
| フォルダの整理 | 「リファクタリングして」 |
| 著者名をそろえる | 「著者名を〇〇に統一してプッシュして」 |
| サンプル記事を消す | 「〇〇を削除してプッシュして」 |
| 空のフォルダを消す | 「空のフォルダも整理してプッシュして」 |
| アクセス数を見られるようにする | 「Google アナリティクス（GA4）でアクセス数を確認したい」 |
| アクセス解析の説明を書く | 「About ページに追加してプッシュして」 |
| うっかりミスを防ぐ | 「main ブランチの保護を設定して」 |

むずかしそうな言葉が出てきても、「**〇〇ってどういうこと？**」と聞けば、Claude Code がわかりやすく説明してくれます。
わからないまま進めずに、気軽に聞いてみるのがおすすめです。

これでブログの土台はしっかり整いました。次は、いよいよ記事をどんどん書いていきます！
