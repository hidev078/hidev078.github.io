「自分のブログを作ってみたい。でも、プログラミングはよくわからない…」

そんな人でも大丈夫です。このブログ「ひでぶログ」は、**Claude Code に日本語でお願いするだけ**で作りました。

この記事では、**実際にどんな言葉でお願いしたか**をそのまま紹介します。まねするだけで、あなたのブログも作れます。

## そもそも何を使うの？

登場するのは、この 3 つだけです。

| 名前 | ひとことで言うと |
| --- | --- |
| **Claude Code** | パソコンの作業をかわりにやってくれる AI アシスタント |
| **Hugo（ヒューゴ）** | ブログを作る道具 |
| **GitHub（ギットハブ）** | 作ったブログを置いて、ネットに公開してくれる場所（無料） |

むずかしい仕組みは覚えなくて OK です。**「Claude Code にお願いする人」になる**、それだけです。

## 準備するもの

- パソコン（この記事では Windows を使いました）
- Claude Code（インストールしておく）
- GitHub のアカウント（無料で作れます）

ブログ用に空っぽのフォルダを 1 つ作って、そこで Claude Code を起動しておきましょう。

## ステップ 1：ブログのもとを作ってもらう

最初はこうお願いしました。

> Hugo を使ったブログサイトをこのディレクトリに新規作成してください。
> テーマには人気のある「PaperMod」を使ってください。
> 日本語向けの設定にしてください。

これだけで、ブログに必要なファイル一式ができあがります。

**PaperMod（ペーパーモッド）** は、シンプルで見やすいデザインのテーマ（見た目のセット）です。迷ったらこれで大丈夫。

## ステップ 2：道具をインストールしてもらう

パソコンに Hugo が入っていないと、Claude Code が教えてくれます。そうしたら、こう言うだけ。

> Hugo をインストールして

インストールまでやってくれます。

## ステップ 3：ブログの名前とメニューを決める

> サイト名を「〇〇」にして、メニューに Home、Posts、Tags、About を置いてください。
> テスト用の記事を 1 つ作って、ブラウザで見られるようにしてください。

すると、**自分のパソコンの中だけで見られるプレビュー**を用意してくれます。
教えてもらったアドレス（`http://localhost:1313`）をブラウザで開くと…自分のブログが表示されます！

ここで見た目を確認しながら、「タイトルを変えて」「この文章を直して」とどんどんお願いできます。

> 💡 **ブログの名前はあとから何度でも変えられます。**
> 「タイトルを『〇〇』に変えて」と言うだけです。

## ステップ 4：インターネットに公開する準備

> main ブランチにプッシュされたときに、自動で GitHub Pages に公開されるようにしてください。

ちょっとむずかしい言葉が出てきましたが、意味はこうです。

- **プッシュ**：パソコンで作ったものを GitHub に送ること
- **GitHub Pages**：GitHub が無料でブログを公開してくれるサービス

つまり「**GitHub に送ったら、自動でネットに公開されるようにして**」というお願いです。

## ステップ 5：GitHub にログインする（ここだけ自分で！）

公開するには、GitHub へのログインが必要です。
これは**あなた本人にしかできない作業**なので、Claude Code が手順を教えてくれます。

1. Claude Code が **8 けたのコード**（例：`ABCD-1234`）を表示する
2. ブラウザで `https://github.com/login/device` を開く
3. そのコードを入力して「承認」ボタンを押す

これだけです。終わったら Claude Code に「承認したよ」と伝えましょう。

> ⚠️ **このコードやパスワードは、ほかの人に教えないでください。**
> Claude Code にも、パスワードを直接打ち込む必要はありません。

## ステップ 6：公開する！

> ブログ用のリポジトリを作成してプッシュして

**リポジトリ**は、GitHub の中の「ブログ置き場」のことです。名前を聞かれたら、

**`あなたのGitHubユーザー名.github.io`**

を選ぶのがおすすめです。すると、ブログのアドレスが `https://あなたのユーザー名.github.io/` というスッキリした形になります。

1 分ほど待ってからアドレスを開くと…**あなたのブログが世界に公開されています！** 🎉

## 公開したあとの使い方

ここからは、もっとかんたんです。

| やりたいこと | Claude Code へのお願い |
| --- | --- |
| 記事を書きたい | 「〇〇について記事を書いて、プッシュして」 |
| 書いた記事を直したい | 「さっきの記事を、もっとわかりやすくして」 |
| 記事を消したい | 「〇〇の記事を削除してプッシュして」 |
| 見た目を確認したい | 「プレビューを起動して」 |
| プレビューを止めたい | 「サーバー止めて」 |

**「プッシュして」と最後に付けると、ネットのブログにも反映されます。**
付けなければ、自分のパソコンの中だけの変更になります。

## うまくいかないときは

むずかしく考えなくて大丈夫。Claude Code にそのまま聞きましょう。

- 「記事が表示されないんだけど、なんで？」
- 「エラーが出た。どうすればいい？」
- 「今どういう状態か教えて」

原因を調べて、直し方まで提案してくれます。

ちなみに今回もいくつかエラーが出ましたが、ぜんぶ Claude Code が原因を見つけて直してくれました。たとえば「記事の日付が未来になっていて表示されない」なんてことも。人間だとなかなか気づけません。

## 気をつけること：ブログは「世界中から見える」

GitHub Pages で無料公開するブログは、**ブログの中身もファイルも、世界中の誰でも見られます。**
次のものは書かないようにしましょう。

- パスワードやログイン用のコード
- 本名・住所・電話番号などの個人情報
- 人に見せたくない写真やスクリーンショット

Claude Code に「**セキュリティに気をつけるルールを CLAUDE.md に書いて**」とお願いしておくと、作業のたびにそのルールを守ってくれるので安心です。

## まとめ

ブログ作りで実際にやったのは、これだけでした。

1. Claude Code に「ブログを作って」とお願いする
2. ブラウザで見た目を確認しながら、名前やメニューを決める
3. GitHub にログインする（ここだけ自分で）
4. 「公開して（プッシュして）」とお願いする

**コマンドを覚えなくても、日本語でお願いするだけでブログは作れます。**
「やってみたいな」と思ったら、まずは Claude Code に「ブログを作りたい」と話しかけてみてください。
